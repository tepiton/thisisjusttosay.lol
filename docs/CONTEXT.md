## Context

- Site is a minimal image-gallery frame (monospace, black/white, one photo via Flickr URL).
- `index.html` is hand-edited directly — no templating/build step in this repo.
- Layout is viewport-locked: `html, body` use `height: 100vh`/`100dvh` + `overflow: hidden`, so the page never scrolls, it clips instead.
- Frame sizing fixed in two passes (`1f60fa5`, `f227677`): `figure`'s `height: 100%` had nothing solid to resolve against inside `main`'s `place-items: center` cell (auto-sized to content), so the frame could overflow past the footer on short/wide viewports. Fixed by switching `main` to `justify-items: center` (leaving vertical `align-items` at its default `stretch`) so `figure` stretches against the real grid track height, then derives width from `aspect-ratio` and caps with `max-width: 100%`.
- History: Mimeo scaffold → embedded picture HTML → hosted Flickr URL → made it the front page → prettyprinted + locked to viewport height → fixed frame overflow on short viewports.
